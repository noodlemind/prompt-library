# Continue an accepted experiment

Use this reference only when the accepted full plan declares `experiment`. The Engineer proposes one hypothesis; Harness owns budget, measurement and restoration. Planning remains with ensure-plan. Initial support is one tracked finite JSON weights file against one frozen `linear-json-v1` workload on a supported macOS runtime. Executable candidates, timing/noisy measurements, domain experiments and external side effects are unsupported.

1. Read the full `.hplan` contract and `ae experiment status --plan <path> --json`. Require a locked active plan, current project trust, a registered linked issue worktree and a fresh implement gate. Read-only status never probes isolation or performs recovery.
2. Reserve the untouched baseline with `experiment begin --plan <path> --file <decision.json>`. The decision has `version: 1`, a unique `id`, the current raw plan SHA-256 in `expect`, and one bounded `hypothesis`. Harness returns `attempt_id`. A reservation spends two invocation slots before either child starts.
3. Run `experiment evaluate --plan <path> --attempt <attempt_id>`. Read the validated metric and hard correctness results. Stdout is not a score. The same invocation cannot launch twice. Use `experiment resolve` with a revision-bound decision containing `version`, `id`, `expect`, `attempt`, `decision: keep|discard|cancel`, and `description`. Keep the baseline before editing a candidate.
4. Reserve one candidate hypothesis, edit only its exact accepted JSON file, evaluate once, then keep or discard it. Keep requires current evaluator/artifact identity, hard correctness and the declared minimum improvement. Discard restores recognized candidate bytes and modes to the last kept snapshot while preserving unrelated work and the user's index. Unknown bytes block restoration and remain intact.
5. A failed or interrupted attempt still spends its slots. Explicit evaluate/resolve can recover a recorded operation only after its owned child groups are proven gone. A repair reservation names the failed attempt as `repair_of` and repeats its original hypothesis. At most two charged repairs fit within the original global limits. More budget requires an authored `experiment-intent` amendment on this same plan; it never resets the baseline, origin or spent count.
6. Stop at target, exhaustion, cancellation, invalid evaluator or unknown ownership. Return unmet criteria to the Engineer. After a correct target is retained, finish ordinary task/criterion progress, required review, final behavioral `ae verify`, learning/no-learning and the complete decision. Final proof does not run an unbudgeted scorer.

CLI, hydrated hooks and corpus must be the matching release. A declaration cannot substitute for the actual sandbox probe or retained measurement artifacts. This workflow adds no autonomous model loop and makes no model-quality claim.
